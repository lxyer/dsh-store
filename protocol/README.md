# `@dsh-store/protocol`

Open JSON Schema and validators for DSH Store.

Schemas live in `schemas/` and are the contract third parties should consume:

- `plugin.json` / `plugin-version.json`
- `passport.json`
- `pack.json` / `pack-lock.json`
- `install-target.json`
- `capability.json`
- `search-query.json`

`examples/` contains the section 4.6 pack and section 6.2 install target used as Phase 0 acceptance fixtures.
